## Available Examples

### Cypress to Playwright Migration (with Copilot)

Practical examples and patterns for migrating E2E tests from Cypress to Playwright, including how to accelerate the process using GitHub Copilot.

Includes:

- test conversion patterns (Cypress → Playwright)
- selectors and locator migration
- network mocking (intercept → route)
- authentication and session handling
- CI/CD migration
- using Copilot to refactor and generate tests
